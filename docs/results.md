# 路线比较、状态修正与交付结论

## 决定

保留真实＋联合文本LR为共同识别路线，BM25保留研究候选；将门控、历史保护、近期权重按顺序分别核验并接入v5状态。没有为贴合申报书强行加入相似度，也没有把真实数据丢掉。

“合成参照”仍用真实评分校准生成器；本次BM25还使用真实训练内部的折外查询拟合分数映射。真实留出文本继续评价。是否直接把真实原文放入分类训练，是可比较的设计变量，不是真实数据有没有用的分界。

## 识别结果

同47人、五次重复四折。首轮沿用旧折内联合语料，当前LR逐条预测复现；后续改为和首轮同一学生外层切分，避免一条链两轮的训练/留出身份不一致。模型分数不是心理测量概率。

| 阶段/方案 | 宏F1 | 准确率 | 低→高误判 |
|---|---:|---:|---:|
| 首轮：真实＋联合文本LR（保留） | 0.678 | 79.6% | 10% |
| 首轮：仅联合文本LR | 0.572 | 74.5% | 50% |
| 首轮：合成参照BM25＋真实内层映射 | 0.612 | 71.1% | 40% |
| 首轮：混合参照BM25＋真实内层映射 | 0.459 | 52.3% | 5% |
| 首轮：仅真实文本LR（强对照） | 0.734 | 81.7% | 0% |
| 后续：真实文本LR（保留） | 0.599 | 63.0% | 0% |
| 后续：真实参照BM25＋真实内层映射 | 0.341 | 37.9% | 4% |

原始BM25直接按类检索分argmax仍为：仅合成0.726、混合0.638、后续0.416。本次映射后成绩下降，不覆盖原结果，也不能推断所有校准方法或所有BM25都无效。当前证据表明这套映射和系统接口没有带来足以替换现行LR的整体收益；原始仅合成BM25虽高F1，低类误判高类30%，不能只按最高F1部署。

后续0.599与过去0.611采用不同外层划分，不是更换算法导致退步；全量重新拟合的首轮/后续模型，对94条文本的分数与旧r3最大差分别约1e-15、4.6e-15，数值等效。新版本的主要改变在状态层。

当前整体标签不改。四维真实均值仍主要服务生成；没有冒充自动ALSP量表或原完整风险公式。仅真实强对照仍优于混合F1，因此不宣称合成增强已提高真实任务表现。所有候选属于已有开发库的内部比较。

## 新证据接纳

在各外层训练内部生成预测，再按事先规定规则选首轮/后续门槛：接纳后等级一致率至少85%、原确认误更新0，满足时最大化覆盖；外层只评价，不参与选门槛。85%是工程设计目标，非文献认证的教育学标准。

| 阶段 | 固定旧门槛覆盖/接纳后一致率 | 训练内选门槛的外层覆盖/一致率 | 每次平均错误更新 |
|---|---|---|---|
| 首轮47条/次 | 41.7% / 93.8% | 71.1% / 87.7% | 1.2→4.0 |
| 后续有等级33条/次 | 14.5% / 100% | 49.7% / 80.2% | 0→3.2 |

确认/非提问14条另列，本轮两种方案在外层均没有把原确认更新为依赖变化。接纳一致率不是全部表达的识别准确率。

**收益是新证据不再大量被搁置，代价是增加错误更新；后续外层80.2%并未达到训练设计的85%。**本版本是供正式比较使用的透明工作点，不把覆盖提高当成无代价改进。若后续审核认为错误成本不可接受，应按新协议调整，保留本版作参照。

全47人训练内选择的运行门槛为首轮0.45、后续0.50。上述49.7%来自各外层折自己的训练内选参，不能保证现场固定0.50会达到同样覆盖；现场身份与表达分布也未验证。

## 历史保护与近期权重

比较旧强保护和证据感知保护后，采用：明确非高行为证据可解除历史强覆盖；模型非高证据累计两次有效更新后可解除；明确索答立即高档；确认、冲突和无证据不伪装成改善。解除路由保护不清零累计R。新增连续非高有效证据计数并完成会话序列化验收。

固定接纳与保护后，在六种预写工程信号（上下阶跃、单次尖峰/低谷、波动、渐变）中比较alpha：

| alpha | 相对构造目标的平均MSE |
|---|---:|
| 0.50 | 0.021188 |
| **0.65** | **0.020223** |
| 0.80 | 0.024237 |

采用0.65作为工程参照。优势较小，结果依赖所设信号；不是儿童长期行为最优值。逐情形切换次数、响应延迟及完整轨迹保留，不用模拟变化替代真实行为变化。
