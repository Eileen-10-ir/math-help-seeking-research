# 当前参数化数据路线与申报书的关系

当前正式名称：**真实特征校准的参数—行为—文本受控生成**。它是数学主线的数据生成实现，保留真实校准、受控覆盖和可复现的研究目标；建模对象和表达实现较申报书有实质调整，应如实说明。

## 1. 完整流程

**真实训练数据校准 → 抽样行为配置 → 联合表达器组合数学任务与语言部件 → 去重、程序核验与独立抽审 → 得到合成学生prompt → 训练识别器并用真实留出文本评价。**

这是完整研究流程图；其中独立人工抽审尚未完成。当前已用通过程序检查的候选语料开展开发性训练与评价，不能把它称为已完成人审的正式语料。

|阶段|输入与处理|输出|
|---|---|---|
|真实校准|只用该训练折学生的最终标签、逐条ALSP双人均值；保留四维组合，不独立打散抽四个分数|同类别供体及可追溯目标特征|
|配置抽样|在兼容类别的工程配置中，按与目标特征的距离、tau和种子抽样|需求、学习目标、参与形式、信息布局等spec；不是直接把四维加总切等级|
|联合表达|题目/卡点、参与、需求、学习目标部件按spec组合；数学系数及步骤按规则计算|模拟学生的具体提问及题目上下文，不是系统给学生的回复|
|核验与抽审|数学遮罩后去重、配置契约/数学结构检查；部分双人独立审核语义与数字锚点|候选有效性、缺陷及修订记录；程序通过与人审通过分开|
|训练与评价|分别比较仅合成、仅真实、真实＋合成；当前冻结运行参照使用真实＋联合文本|识别器、真实留出预测与误判分析；不把合成测试高分当真实效果|

联合表达器将G1的参数控制与数学/语言部件串联，不是旧G0/G1两批语料简单相加。原真实整体标签保留；合成整体等级是生成条件、仍需核验。新审核数字分不自动替换旧均值或生成器锚点。

## 2. 与申报书原设想比较

|项目|申报书原设想|当前实现与取舍|
|---|---|---|
|建模对象|学生逐轮依赖倾向d、表达水平e、改善概率p，结合学生类型、趋势和扰动生成轨迹|以真实ALSP组合校准单轮行为配置，再实现为prompt；未用现有两轮数据估计完整学生动态/改善概率模型|
|标签来源|潜变量与分级阈值形成模拟等级，再映射prompt模板|真实整体标签沿用最终结论；同类别抽样生成候选，不以新分项细则推翻旧整体标签|
|语言表达|已有模板映射，并计划LLM同义、口语化、模糊和对抗扩展|当前使用版本化句库与数学组件，运行时不逐条调用LLM；句库设计/代码有AI辅助；独立审核和更广表达扩展另行验证|
|真实数据角色|主要校准参数并作外部验证，不作为核心训练来源|训练折用于校准；混合组还直接加入真实训练文本，留出学生评价。原47人已反复用于开发，属于内部回顾性评价|
|多轮含义|潜在学生状态随干预更新，可生成多轮行为轨迹|在线由实际输入推动识别/门控/EWMA/画像更新；构造序列只验证工程响应，不证明学生改善|

**原方案本身就包含prompt模板映射。**因此差别不宜表述为“原来参数化、现在只剩模板”；关键变化是从完整潜在学生动态模型，收敛为当前数据可校准的单轮条件文本生成，并将真实行为效果单独验证。

## 3. 为什么当前可以保留使用

它把真实校准、抽样条件、实现文本、训练切分与错误来源连接起来，便于复现、审核和按行为类型诊断。新联合数据已完成训练接入并跑通识别—状态—画像—连续交互—三路支持，因此可作为当前研究实现与正式比较的共同基础。

但“工程可用”“有机制分析价值”和“提升真实识别/学生学习效果”是不同结论。当前仅真实强对照仍高于冻结混合参照的宏F1，数量实验也不支持合成越多越好；保留该方法不意味着已经证明增强收益。独立抽审、去掉校准信息/质量过滤等对照用于进一步确认贡献，正式回复质量—资源比较仍需实测。

对中期汇报可表述为：

> 我们保留申报书中真实校准和受控生成的思路，将参数化对象具体化为可观察的求助行为组合，并增加可追溯的文本实现与审核环节。当前数学全流程已经跑通；生成方法的独立语义质量和下游增益，通过后续审核及对照分别检验。
