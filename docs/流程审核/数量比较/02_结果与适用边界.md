# 合成数量比较结论

**现有表达器不是合成越多越好。本轮可行网格中，仅真实训练是固定预算表现最好的组。**

|首轮训练方案|5次学生折外宏F1均值|准确率|高类召回|低类召回|低→高|
|---|---:|---:|---:|---:|---:|
|真实＋0条|0.7341|81.70%|58.33%|50.00%|0%|
|真实＋45条|0.7016|80.85%|66.67%|40.00%|15%|
|真实＋91条|0.6794|80.43%|66.67%|35.00%|15%|
|训练内一标准误差选数量|0.7445|81.70%|63.33%|50.00%|0%|

低类每次只有4人，15%是5次重复预测的均值（共20次低类预测中3次），不是15%的独立新学生。每个学生每个固定方案被预测5次，独立学生仍47名。嵌套流程20个外层切分中14次选0、6次选45、没有选91；嵌套流程不是单一已部署的45条或0条模型。

固定方案和嵌套选型的分数来自相同小样本内部重复切分，不按0.7445−0.7341就声称显著改善，也不把外层最优叫独立确认。当前研究者已反复接触原样本，属于回顾性内部评价。全量部署若要采用数量选型，须在全量训练内执行相同选型、重新训练/门控/全线验收，不能把20折多数票直接写成全量最优。

容量方面，364在首个外层、182在首个内层视图耗尽遮罩后唯一同义表达；91通过全部80视图。因此按结构可行性、在看分数前缩小网格。不能宣称91是数学上限，更不能宣称任意大数据扩展已经实现。

这次比较固定类别比例36:36:19、tau1、表达器v2与文本LR，仅回答这个条件下的数量问题；未同时优化类别比例、tau、语言库、质量过滤和算法。旧共同主线91条沿用各外层旧tau，这里的91固定tau1，0.6794与旧0.678的差别不能全部归到数量。

**使用决策：**保留已跑通的共同版本作可复现参照；正式实验必须呈现仅真实强对照，暂不把91称最佳训练预算或宣称合成增强胜出。合成的高类召回收益伴随低类误挡，应继续独立语义审核、定向质量过滤及小预算校准，而非直接扩大数量。云/边/协同的策略对比仍可在同一识别器下公平执行；是否更换其公共识别器，应另定版本后统一验收，不能各队友自行换不同版本。
