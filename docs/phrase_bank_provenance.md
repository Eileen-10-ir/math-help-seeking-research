# 固定语言部件的来源与AI辅助说明

**当前句库主要来自我们在本地完善生成器时新增、复用和修订的工程设计，由Codex辅助编写/实现；不是队友交来的一套现成语言库，也不是从论文直接摘取的标准措辞。**

|来源层|能追溯到的材料|贡献|
|---|---|---|
|队友原交接|9月10日交接文档及9月15日识别线报告（私有档案）|SQLite标签/取数、文本识别、标准化、数学遮罩与意图特征等；在已核对交接文件中未发现当前REQ/LEARN/TRIED句库|
|本地G0工程实现|[controlled_text.py](../src/frozen_core/数学主线严谨重跑20260930/code/controlled_text.py)，GRAMMAR和tasks|早期类别表达、四类数学任务；不是现成学生表达分布|
|本地G1实现|[g1_generator.py](../src/frozen_core/G0_G1严谨对照20261014/code/g1_generator.py#L27-L37)，REQ/LEARN/TRIED|按需求、学习目标、参与表达拆分的预写句库；2026-10-14候选版本|

真实评分校准同类供体及配置的抽样倾向，不自动学习这些句子的措辞。四维定义和原整体标签提供设计约束，具体句子是工程编写。不能把我们设计的文字归功为队友原始交付、真实学生原话或某篇论文原句。

## “没有调用大模型”的准确含义

**运行生成器时不逐条调用大模型API：**给定参数/任务/风格索引，固定句库与数学组件确定性组合。**这不表示设计过程没有AI辅助：**句库及代码是在本项目协作中由Codex辅助编写和修订的。二者应同时披露。

可以这样写方法说明：

> 我们设计参数—行为—文本受控实现器，使用AI辅助编写和修订的版本化语言部件及数学任务组件。真实训练特征校准配置抽样，运行阶段按规则组合，不进行逐条自由语言模型生成。独立语义审核另行实施并据实报告。

可解释、可复现是当前优点，自然性、多样性、标签措辞捷径及配置错配仍需检验。不能仅因句库可追溯就称已验证真实分布或增强有效。完整实际句库见[text_generation.md](text_generation.md)，统一审核见[semantic_review_codebook.md](semantic_review_codebook.md)。
