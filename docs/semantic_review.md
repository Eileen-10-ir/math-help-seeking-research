# ALSP部分审核入口

**先读[统一判断细则v1](semantic_review_codebook.md)。**它完整规定审什么、代码怎么选、哪些情况不应推断、阶段二怎样对照配置、缺陷怎么处理和一致性怎么计算。

这是审核现有合成文本与实现配置的对应，不是重新打分真实学生，也不是评分系统回复。复用44条覆盖材料，两人先独立盲审文本，锁定回交后再核对目标；原整体标签与原实验保留。

- [阶段一空表](review_templates/semantic_stage1_blank.csv)：只看题目/文本，填可见A/L/P/S、证据和不确定原因。
- [阶段二空表](review_templates/semantic_stage2_blank.csv)：解盲后填四维对应/错配/不明确及处置。
- [机器可读枚举](../configs/semantic_review_codes.json)：与细则使用相同字段代码。

仓库空表只有表头，没有学生原文或44条待审内容。带内容的A/B各阶段表及解盲键在本地私有审核材料中提供。不要提前发解盲键；审核尚未完成，不填写虚构通过率或κ。
