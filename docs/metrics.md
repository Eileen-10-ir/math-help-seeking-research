# 数据、版本与指标：所有成员共同口径

## 数据与标签

- SQLite：`统一数据与交接准备20261014/data/数学真实94条_研究只读导出.sqlite3`。47人、两次表达；samples保存sample_id/student_id/round/pair_id/prompt_text/final_level；r1_scores保存47条首轮双人四维分与均值；provenance保存来源。
- 首轮高/中/低12/31/4；后续7/21/5，确认/非提问14。整体标签保持，后续没有四维人工分。不用问卷自选类别代替最终标签，不为提高κ或实验成绩改标签。
- 联合v2：真实训练供体整组A/L/S/P均值→兼容配置的距离抽样→题目/语言部件→文本。参数、目标与实现配置是工程信息，不是新人工评分。S不直接写入当前风险值；ALP重要性保留，但尚未自动逐维验证。
- 外层语料1820=20切分×91条；使用seed/fold对应部分。内层重新只用内层训练供体生成，不将外层语料带入内层。全量运行另用91条（tau1.0、seed20261014）＋47真实，共138条。后续全量47条真实。
- 外层首轮继承旧G1同折tau，内层生成固定tau1.0；这个不同拟合设置已记录，后续新表达器选参/消融可以扩展，不能称已寻得生成参数全局最优。

## 版本与分层

当前模型math-joint-v2-state5-20261018；首轮mixed_lr、后续following_lr；状态v5、首轮cutoff0.45/后续0.50、alpha0.65、历史参照阈值0.5；支持v7。原r3和旧G0/G1结果保留为历史来源。BM25是比较候选，当前没有用于线上分类。

本轮数据1645=7个阶段/方案×47人×5次预测，仍47名独立学生。仅真实/混合/合成参照的角色分开记录：真实既可校准生成器，也可监督分数映射、直接加入分类训练；留出真实文本用于评价。开发中反复接触的数据不称全新外部验证。

## 指标及分母

| 层级 | 指标 | 分母/计算 |
|---|---|---|
| 原始分类 | accuracy、逐类precision/recall/F1、macroF1 | 每次47条学生留出表达；首轮3类，后续4类；先每次计算再平均 |
| 严重误判 | 低→高、高→低 | 分别以真实低类、真实高类为分母；首轮低类4人×5次=20重复预测，非20名学生 |
| 模型分数 | 多类Brier | 每条所有类别与one-hot原标签的平方差之和，再平均；不称心理量表校准 |
| 状态接纳 | 更新覆盖、接纳后等级一致率、错误更新、ACK误更新 | R1有等级47条/次；R3有等级33条/次；ACK14条单列；保持回合也报告 |
| 动态响应 | 解除延迟、误切换、抖动、构造MSE | 明确列出构造情形、目标、有效更新和总消息数；不是学生改善率 |
| 系统执行 | 计划数、完成率、调用率、成功率、失败率 | 每策略全部计划病例/回合；调用成功以实际尝试为分母，失败不删 |
| 回复质量 | C/T/A/H分布、均值、适用项及NA数 | 适用且已评分输出；缺评和执行失败分别留存 |
| 有效支持U | 评分规程定义的有效支持率 | 完整评价的全部计划回复；失败U=0，待评分不强赋0；另报成功输出中比例 |
| 披露/阻断 | E披露率、R不必要阻断率 | 各自可判定适用项；披露不等于数学错误，不必要阻断不等于API失败 |
| 资源 | 端到端/模型/API耗时、median/p95、token、费用 | 实际执行；失败与成功分开；缺usage/价格记未知，dry-run不填真实云耗时/费用 |
| 性价比 | 总费用/有效支持数，及对全云费用节省率 | 记录完整且分母>0时计算；没有有效支持不报0成本 |

旧固定8病例×2重复×4策略=64条，单策略16条。该批是工程初验，正式扩展需先冻结病例与批次。质量评分以病例/题目聚类配对，重复生成、两名评分者、两次问卷不算新增独立学生。

原问卷10/47人等级下降仅为历史观察；不归因于现网页。确认/非提问不当作改善；输出质量、行为调整、学习成绩分别报告。新联合版没有根据回复生成下一轮学生行为的已验证生成器。
