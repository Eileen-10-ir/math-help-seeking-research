# 参数怎样变成文本：当前实际使用的语言部件

**这里的部件是研究者预写的短句及数学任务组件，不是从学生原文自动学到的句子，也不是本次调用大模型生成的。真实训练评分校准配置抽样倾向；语言库、类别兼容边界和实现锚点由研究者设计。**

## 组合过程

`同类训练供体的ALSP均值 → 按tau距离抽配置 → spec → 题目/卡点＋参与表达＋求助表达＋学习目标 → 遮罩去重/程序审核 → 部分独立人审`。候选整体标签是生成条件，独立语义审核尚未完成。

字典里REQ每组8句、LEARN每组8句、TRIED8句；当前联合v2的风格索引为0—5，**实际使用前6句**。下面逐字列出这部分活跃句库；不要把字典备用的第7/8句算成当前已投入生成的措辞。

## A：求助范围

### high，工程A锚点1

- 请直接告诉我最后答案。
- 把最终结果给我。
- 这题的答案是多少，直接报结果。
- 我需要这题的得数，替我算出来。
- 直接把结果写给我吧。
- 帮我算出最终答案。

### high，工程A锚点2

- 请把从头到尾的解答和结果都写出来。
- 把完整过程和最后答案一起给我。
- 请替我完成整道题的推导和计算。
- 从第一步到最后结果都帮我写好。
- 帮我写一份完整解答，包括答案。
- 把每一步和最终结果全部算给我。

### medium，工程A锚点3

- 这题应该怎样运用{concept}？
- 请讲讲{concept}在这题中的解题方法。
- 这道题用{concept}该怎么起步？
- 能解释一下这题的{concept}思路吗？
- 我需要理解{concept}在这里怎么用。
- 请教我这题的{concept}方法。

### medium，工程A锚点4

- 请解释{concept}的依据。
- 我想问{concept}为什么能这样用。
- {concept}的原理能讲一下吗？
- 这题涉及的{concept}是什么意思？
- 请说明{concept}成立的理由。
- 能讲清楚{concept}背后的道理吗？

### low，工程A锚点4

- 请检查我这一步的依据。
- 帮我核对这一步有没有问题。
- 我写的这一步是否合理？
- 请指出我这一步哪里需要检查。
- 帮我看看这一环的理由对不对。
- 我这一步的逻辑成立吗？

### low，工程A锚点5

- 只提示我下一步该想什么，剩下的我自己算。
- 请只核对这一环，不要替我把后面做完。
- 给我这一小步的提示就好，后续我自己做。
- 我想自己继续，请只指出这一步要检查什么。
- 别直接给最后答案，只帮我理解这一处。
- 只解释我这一环的依据，结果让我自己算。

中类A=4在联合表达器中被以下“当前题内理由需求”覆盖，不直接使用上面medium/4的泛概念句：

- 这道题为什么要用{concept}？请讲清楚起步思路。
- 请解释{concept}在这道题中的用法，我还没有具体做法。
- 这道题运用{concept}的依据是什么，应该怎么开始？
- 我想了解这道题用{concept}时先考虑什么。
- 能说明这道题使用{concept}的思路和理由吗？
- 请带我理解这道题中{concept}的起步方法。

## P：参与与尝试

P=1不添加尝试句，不能据此推断学生实际没有思考。P=3使用以下“声称想过，但未展示步骤”的句子：

- 我想过一会儿，但还没列出具体步骤。
- 我试着想了，但没有写出式子。
- 我考虑过了，暂时说不出具体过程。
- 我自己想了一下，还没有成形的步骤。
- 我试过思考，不过还没写出推导。
- 我想了一阵，目前没有可展示的步骤。

P=4/5使用题型组件中的方法线索/具体数学步骤。部分低类行为类型有独立表达：

- 自主声明：“我想自己把这道题做出来。”等三种措辞。
- 已会完成：“这道题我能自己完成。”等三种措辞；不必强塞一个新问题。
- 拒绝代答的方法需求：“不要直接给我答案，请教我从哪里开始。”等三种措辞。

这些特殊行为由behavior_type控制，不能只按P分数推断全部内容。

## S：信息呈现

|工程S锚点|实现|
|---|---|
|1|“这题。”，依赖已给题目上下文|
|2|“关于{concept}。”，只给主题|
|3|题目或局部上下文；低类可省略重复题干|
|5|明确题目，并加“我不明白{focus/next}。”表示卡点|

S在此控制表达方式，不直接增加线上依赖风险；口语与依赖不能混同。

## 数学组件

四题型分别提供question、concept、focus、clue、step、next。以二次方程q0为例：题目为“解方程x²−6x+8=0”；concept为“因式分解”；clue为“我想到用因式分解，要先找两个合适的数”；step为“我先写成(x−2)(x−4)=0”；next为“为什么乘积为零时可以分别考虑两个因式”。系数按task_code的规则计算，不能任意填一个数学错误的步骤。

## 组合示例与审核重点

题目＋方法需求＋当前题理解目标，可以得到：

> 解方程x²−6x+8=0。这题应该怎样运用因式分解？我想弄明白这道题。

它是合成示例，不是真实学生引文。审核要看需求、目标、参与、信息是否兼容，是否有数学错误/重复/矛盾/过于像标签口号。固定句库可解释、可复现，但自然性和多样性受限；仅换数字不等于增加独立表达，182/364容量不足也反映当前库的限制。

ALSP部分审核是先盲审这些生成表达，再解盲核对实现配置；不是重新给47名学生打分，也不要求把自然语言精确重打成供体均值。详见[审核协议](semantic_review.md)。
