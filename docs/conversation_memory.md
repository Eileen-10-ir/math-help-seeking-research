## 目的与位置

接住学生已经提供的题目、思路、步骤和结果，减少重复索取、退回第一步及跨题混淆。

```text
当前原文 → 原识别器 → 原证据接纳/EWMA → 原最终档位
实际问答 → 证据字典/有向关系 → 当前题目与相关原话 → 分级支持
```

`src/conversation_memory.py`保存带角色、回合、原文片段和题目关联的节点及关系；原始会话仍在turns，派生图存入同一SQLite的evidence_memory表。不是另建图数据库，也不训练图神经网络。

有来源不等于语义或数学正确。助手提示不当作学生自主步骤；“好的”不表示掌握；错误步骤仍可记录为学生表达。明确换题、返回和修订才建立相应关系，未知指向单列。历史不会进入原分类器，也不因此重算ALSP或降低EWMA。

## 运行

先按README恢复私有模型和依赖，再运行：

```powershell
python -s -X utf8 run.py serve-memory --port 8772
```

默认v12-memory-only只增加记忆及更新本地引导措辞，分级与支持路径保持；可用`--mode recent`或`--mode summary`与默认graph作对照。各组最多2600字符历史资料，实际token另记；不声称是等token比较。

另一个完整候选：

```powershell
python -s -X utf8 run.py serve-memory --port 8772 --continuation-help --refined-guidance
```

该v12另启明确变化：未分级但有实际题境的方法/理由追问、步骤/结果核对可走受限云，原等级与EWMA保持；中类模板允许核对学生已经给出的候选结果。最终高仍本地，最终低仍直接云，最终中仍附模板后云。未分级桥单列，不能伪写成测得中依赖。

限制模板全文见`src/memory_support.py`的REFINED_SUFFIX，配置接口和逐条导出记录实际发送的模板。纯云不添加这一模板。

v12对受限云另做局部输出检查：若发现未在本题实际历史/当前文本出现的显式单变量数值结果，最多尝试一次受限改写，generation_attempts保留全部实际输出和消耗；仍不符合才显示本地提示，route_executed记cloud_reply_withheld_local_hint。它不能检查所有自然语言、复杂公式或等价变换，不能冒充完整语义验证。

## 输入输出及参数

|模块|输入|输出|参数来源/限制|
|---|---|---|---|
|EvidenceMemory.from_records|实际学生输入、已交付支持及状态、可选题干|事件、节点、带来源关系、当前题视图|保守规则设计，未用新人工标签训练|
|memory_messages|记忆、历史、当前文本、模式|限定字符上下文和构建元数据|2600为固定工程预算，未称最优；零构建API|
|context_interpretation|当前文本及本题前置证据|核对/索答/步骤/确认/待澄清诊断|仅诊断，不输出或覆盖依赖等级|
|make_support|原分析结果、实际历史和云网关|请求/执行路径、回复、使用的记忆、模板、检查结果|v9记忆与v11策略分开评价|
|MemoryService|原会话请求|原分类状态画像＋记忆导出|原识别模型及状态文件不变，派生图可重建|

`tests/test_conversation_memory.py`及`tests/test_memory_runtime.py`可用标准unittest运行。完整服务入口保持原本机地址、来源校验和重复提交保护。

## 已有证据
