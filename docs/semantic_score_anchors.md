# ALSP数字评分锚点：0代码＋1—5分

版本：`semantic-score-audit-v1-20261019`。供合成文本抽审试评分、讨论与冻结；不是已验证心理量表。与[语义审核细则](semantic_review_codebook.md)配套：语义类别说明“表达了什么”，数字分项说明本规程下的程度，不能只填数字而不留证据。

## 1. 与原评分保持什么关系

核对的原始《数学标注规范_简化版.md》第一、二节明确采用1—5分，1/3/5为主要锚点；《标注细化准则_第二版.md》第二节明确四维均为5分较优。旧真实分数和逐条双人均值原样保留。

本表补充2/4档、处理无法判断、明确上下文和参与边界，**只用于新合成审核字段**。原L/S及自主参与边界本来有分歧，不能声称本表与所有旧分数严格等值。

**0不是最高依赖，也不是“没有尝试/没有学习目标”的一律零分。0表示此维无法评分，应同时记录原因；统计时视为NA，不能参与均值或被当作第六个有序程度。**有明确证据“只想完成”可给L=1；没有表达目标、无法判定时L=0。

## 2. 逐档标准

|代码/分|A：对最终结果的非索取与帮助边界|L：可见学习目标|S：结合现有上下文的信息清晰度|P：可见自主参与证据|
|---|---|---|---|---|
|0，无法评分|既无可识别求助目标，也无明确自主陈述；或必要材料不可得|没有表达可判断的学习目标，或冲突不能消解|待评价文本/必要图文材料未提供，无法区别是缺材料还是表达问题|只有确认/无关碎片，或无法判断是否是学生自己的尝试|
|1|明确索要最终结果或整题完整代做，无帮助范围限制|明确只想填答案、交作业或完成任务|材料已完整提供，但学生表达仍不能定位要问什么|可正常理解的求助中没有展示尝试、方法或自主声明；不推断现实中没有思考|
|2|宽泛要求整题求解，未明确到最终结果，也未限制帮助范围，如“这题怎么做，帮我解一下”|笼统表达想学/求教，未说明要理解什么|能辨认主题/大概需求，但表达本身缺关键条件，需要较多追问|只有自主意愿/能力陈述或自己的答案猜测，没有过程；行为类型仍分别保留，不当作同一种学习行为|
|3|请求方法或讲解当前题做法，但未明确限定只帮助哪一步/不代做|明确要学会或弄懂当前题做法|题目或现有上下文足够，困惑位置仍笼统|明确说想过/试过，但未展示具体方法或步骤|
|4|将求助限定在具体概念、理由、卡点或已有局部步骤，不要求整题代做|明确探究当前题理由、条件或不同方法，仍限当前题|目标和具体环节已定位，但还有一处影响支持选择的歧义|提供自己的具体方法线索或步骤，尚未完整说明推理连接/待解决障碍|
|5|明确保留完成权、拒绝答案/完整代做，只要提示或局部反馈；明确自主完成陈述也可记5，另标其非提问类型|明确要求归纳通用规律、总结同类方法或迁移到其他题|现有题境、具体需求和帮助边界清楚，可直接确定支持；不要求重复题干、书面语或长文本|展示可追溯的思路/步骤及理由，并明确卡点或进行比较/自检；不要求算对|

这些是**离散锚点，不是经数据验证的连续区间阈值**。审核者填整数；两人均值2.5/3.5只表示两次评分的平均，不代表新的依赖类别。拿不准不能随意填半分。

## 3. 按维度的决策顺序

### A

先处理否定/引用，再看实际交给AI的任务范围。明确“给最终答案/整题完整解答”优先记1，即使同时说想学习；学习诉求在L另记。没有明确结果但宽泛要求解整题记2；一般方法记3；具体局部帮助记4；明确拒绝代答并保留完成权记5。

“不要答案但请把整题每步做完”仍是完整代做请求，不能只因出现“不要答案”就给5。纯“好的”不给A=5，应0；“我已经会做这道题”可A=5，但不因此认定学生能力真实提高。

### L

只看表达的目标，不凭长度、礼貌或“不太会”猜。明确只完成任务记1；泛泛求教记2；弄懂当前做法记3；探究当前原理/条件/方法差异记4；通用规律或迁移记5。目标未显示记0。

“先完成再总结规律”可记录多个目标，以最明确的高层目标为主，并备注时间顺序；无法消解的排他冲突记0并写冲突原因。A索答和L学习诉求可能并存，不能用一个维度强行覆盖另一个。

### S

必须结合提供的实际题境。题目已给，“这题我不会”可以是3而非1；“为什么两边可以同时加7”即使很口语，也可能因目标清楚得到5。若图在实际材料中缺失而无法评其表达，记0；若材料完整但学生本身缺关键条件，按1/2评价，不能用0掩盖表达不足。

S衡量本次信息可用性，不直接增加依赖风险。**生成器的information_layout描述表达形式，S审核分描述上下文中的清晰度；两者不一一等同。**deictic表达在题目已给时未必低分。

### P

未显示参与记1，自主意愿/能力声明或只给猜测记2，声称想过但无具体内容记3，自己的方法线索/步骤记4，步骤＋理由＋卡点/自检记5。仅说“老师讲过因式分解”不是学生自己已实施方法；仅“我想自己做”不算演算。

错误步骤仍可按证据完整性给4/5，另记MATH缺陷。若同时有具体步骤，不因为也说“想过了”退回3。P档位是本次可见证据编码，不是能力排名；不同自主声明类型继续用语义标签区分。

## 4. 例子（另备，不进44条正式统计）

共同题目：解方程3x−7=8。

|表达|示范分A/L/S/P|说明|
|---|---|---|
|“直接告诉我x是多少，只要填上结果就行。”|1/1/5/1|信息清楚也可以明确索答，S高不抵消A低|
|“这道题我不太会，教教我。”|3/2/3/1|一般求教而未显示尝试，不因P=1直接重判整体高类|
|“我想弄明白这道题的做法。”|3/3/3/1|当前题学习目标明确，卡点尚笼统|
|“我想过了但没写出来，为什么第一步能两边加7？”|4/4/5/3|理由请求、明确卡点、仅声称尝试|
|“我先两边加7得到3x=15，因为等式两边做相同运算仍相等。接下来系数怎么处理？不要算出答案。”|5/4/5/5|拒绝代答＋步骤理由和卡点；还没明确要求同类迁移，L不自动5|
|“这类方程怎样总结通用步骤？请只讲规律，例题我自己算。”|5/5/5/2|迁移目标和自主意愿明确，仍没有展示已做过程|

0示例：“好的”在没有进一步可评价内容时，四维可均记0并说明是确认；它不是四个最差分，更不能据此判高依赖或学生改善。每维0单独给理由，不强求四维同为0。

## 5. 怎么与生成参数比较

新增A_audit_score/L_audit_score/S_audit_score/P_audit_score，不覆盖旧人标或工程锚点。对应判断仍优先用help_scope/learning_goal/participation_form/information_layout：

- final_answer/full_solution按本表通常A=1；method_or_reason可落A=3/4，具体看范围；显式拒绝代答的方法需求通常A=5。
- understand_current可落L=3/4；transfer应有L=5相应目标证据。
- claimed_attempt应有P=3对应证据，math_step通常至少P=4；达到5还需理由与卡点/自检。自主声明不强制要求P=4/5。
- S按实际题境评分，不机械等于布局代码。

**已发现需核查的编码差异：**当前工程A=2会实现“完整解答”，但原简化人标把完整代做列为1。它说明工程配置不等于已获人评的分数；本轮将差异记录出来，不把数字改到“看起来一致”，也不先改生成器/旧数据。特殊行为覆盖也应记录。

## 6. 统计和使用限制

0按NA处理，报告数量/原因；每维均值只对非0分计算，不能用0拉低。数值一致性可报告原始一致比例、线性加权κ，但只在双方1—5的可评分配对上计算，并同时报告全部44条及可评分配对覆盖；不可计算时记NA。语义类别的普通κ继续按原规程另算，不能混成一项。

不将ALSP加总，不用“0—2高、3中、4—5低”重新切整体依赖等级。总体等级沿用最终标签；合成候选疑点另记。新审核分尚无独立重复评分，不宣称边界已验证可靠，也不把新S当旧S直接重新校准生成器。
