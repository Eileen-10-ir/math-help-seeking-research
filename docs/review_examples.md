# 审核实例速查

这是研究者另外编写的练习例，不是76条待审文本、原学生标签或API实验结果。分数是当前审核锚点的示范，不是独立人评真值。遇到不完全相同的句子，要找证据，不要照词语机械套分。

共同题目为`3x−7=8`，除非明确说明材料缺失。四维独立评分，不能加总后切分整体等级。先查你拿不准的维度，不需要从头背完。

## A 看学生让AI代做多少

|分|完整示例表达|为什么|
|---|---|---|
|0|“好的。”|只有确认，判断不了求助范围；不是最差分|
|1|“别讲思路，直接把最终答案给我，我照着填。”|明确把结果交给AI|
|2|“这题怎么做，帮我解一下。”|笼统要求整题求解，还未限制帮助范围|
|3|“给我讲讲这道题可以用什么方法。”|要一般方法，未限定具体卡点|
|4|“为什么等式两边可以同时加7？”|请求一个局部理由，不是整题解答|
|5|“不要算出x，提示下一步就好，后面我自己做。”|明确保留完成权和帮助边界|

**最易混淆：**“我想学懂，但请把每一步完整写好，再给我最后答案”仍按实际整题代做请求给A=1；学习诉求另在L记录，不能抵消索答。引用“老师说‘直接给答案’不合适”也不能把引文直接当当前索答。

## L 看学生明确想学什么

|分|完整示例表达|为什么|
|---|---|---|
|0|“x是多少？”|只看见结果请求，没有足够证据判断学习目标|
|1|“我只想赶紧交作业，不想弄懂。”|明确只求完成，和没有说目标不同|
|2|“教教我吧。”|一般求教，未说明要理解什么|
|3|“我想弄懂这道题的解法。”|学习当前题做法|
|4|“我想理解为什么两边加7以后仍然相等。”|追问原理或依据|
|5|“这种方程能总结通用步骤吗？我想用它解其他题。”|明确归纳、迁移目标|

**最易混淆：**“不会”不等于不想学；“请详细分析”也不自动等于探究原理。当前题做法对应3，明确问原因对应4，要求一般规律及迁移对应5。

## S 看现有材料能否定位问题

|分|题境及示例表达|为什么|
|---|---|---|
|0|只写“按图片那一步解释”，但审核材料根本没提供图片|不能判断图片里是否已经把问题说清，必要材料缺失|
|1|题干已给，仍只说“弄那个，不是这个，是另一个，你懂的”|材料已有，但所指及需求无法定位|
|2|“我的另一种算法不对，请找错”，但没说算法或写出步骤|知道是检查方法，学生表达却缺必要细节|
|3|题干已给：“这题我不会，教教我。”|题目清楚，具体卡点仍笼统|
|4|“我写到3x=15，想问‘移过去’对不对。”|环节具体，但移哪一项、怎样移仍有歧义|
|5|“为什么等式两边都可以加7？”|问题与帮助范围清楚，口语和短句不扣分|

**最易混淆：**有完整题目时说“这题”可以正常指代，不要因没重复题干给1。0用于判断材料不足；学生表达本身没说清所需细节时，按1/2，而不是一律0。

## P 看表达里展示了什么贡献

|分|完整示例表达|为什么|
|---|---|---|
|0|“嗯，知道了。”|确认回应，不能评估自己的尝试|
|1|“请讲讲这道题的方法。”|可理解的求助，但没展示尝试|
|2|“我想自己做，只给我提示。”|有意愿，还没展示实际行动|
|3|“我自己想了一会儿，但没有写出过程。”|声明尝试，没有可核对步骤|
|4|“我先两边加7，写成3x=15，下一步呢？”|已有具体步骤，但没有展开理由|
|5|“我加7得3x=15，因为等式两边同加一个数仍相等；接下来除以3的依据是什么？”|步骤、理由和卡点均可见|

**最易混淆：**“老师讲过因式分解”不是自己已经实施了方法；“我想用因式分解，先找两个数”则有具体方法线索。步骤算错也不自动降低P，数学错误单独备注。照抄系统刚给出的步骤不当新增自主贡献。

## 整句怎样同时填四项

|完整表达|A/L/S/P示范分|判断依据|
|---|---|---|
|“直接给x的结果，我只要填上就行。”|1/1/5/1|索答和只求完成明确；需求很清楚，所以S仍高|
|“这题我不太会，教教我。”|3/2/3/1|一般求教、卡点笼统，没有展示尝试|
|“我想弄懂这道题的做法，请讲讲。”|3/3/3/1|当前题学习目标明确，但没有具体卡点与尝试|
|“我想过了但没写出来，为什么第一步可以两边加7？”|4/4/5/3|局部理由明确，但参与只停留在声明|
|“我加7得到3x=15，因为两边同加一个数仍相等。接下来为什么能除以3？不要算结果。”|5/4/5/5|不代答、问原理、步骤和理由及卡点都明确|
|“请只讲同类方程的一般规律，例题我自己算。”|5/5/5/2|目标可迁移、帮助边界清楚，但尚未展示已做步骤|

这六行不提供整体标签答案，避免误以为四个分数能直接求和分类。合成文本的整体建议要回到实际请求和已有规范；真实首轮的旧整体标签不改。

## 后续回应怎样判

后续页签不补四维分，先看学生在回应什么。以下假定题目仍为`3x−7=8`。

|实际前次支持|学生后续原句|行为及新增贡献|等级如何处理|
|---|---|---|---|
|“先自己试着做一步。”|“好的，我先试试。”|确认/结束；没有已展示的新步骤|可判断等级=否，等级NA|
|“请两边加7，写出新式子。”|“3x=15。”|作答；有按提示完成的步骤输出，备注“受前次提示支持”|没有新求助需求，等级NA；不自动记改善|
|“加7后是3x=15。”|“加7后是3x=15。”|复述；不计新增自主贡献|没有新需求，等级NA|
|“你先找去掉常数项的方法。”|“我还是不知道怎么开始，给我讲讲一般做法。”|一般方法求助；新增明确需求，未展示步骤|可作为medium示范，不凭“不会”判high|
|“试着写一步。”|“不用引导了，整题每一步和最后答案都写给我。”|继续索答；当前实际请求是完整代做|可作为high示范|
|“想想怎么去掉常数项。”|“我先加7得到3x=15，因为两边同加一个数仍相等；后面为什么要除以3？只给提示。”|展示步骤/卡点；有新增推理和局部帮助边界|可作为low示范；不是由短语“只给提示”单独决定|
|“你可以按‘我做到___，卡在___’说。”|“我做到___，卡在___。”|复制框架且没填实质内容；其他/不清楚|证据不足时否/NA，不给高P或认定改善|
|“你可以按‘我做到___，卡在___’说。”|“我做到3x=15；卡在为什么等号两边都要除以3。”|填入具体步骤和卡点；区别于空框架|按实际需求与证据判断，不因填空就自动low|

一个句子同时有步骤和问题时，行为类型选最主要的一项，证据列保留两部分。新增贡献选最具体的一项，其余在备注说明，使用表内下拉代码，不自行增加新代码。

等级NA表示本次没有足够的求助等级判断依据，不等于学生没有依赖。当前帮助需求可以写“无”。模糊边界不要硬套此表，写原句和犹豫点；原独立分保留，回交后再讨论。
