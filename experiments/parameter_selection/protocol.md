# 2026-11-18补充实验执行协议

本协议在新增实验结果产生前保存。原数据、标签、旧结果与队友代码只读。新增结果是反复开发背景下的内部回顾性评价，不称外部验证。

P1：复用五次学生分组四折；内层最多3折，少数类不足时2折。首轮仅真实、混合均比较C={0.25,1,2,4}、字符窗口上限={2,3,4}、balanced/无权重，共24组。后续同24组。固定外层学生分组；每个内层训练集独立生成与拟合词表。混合先以τ=1、合成量2倍真实、旧配比选识别参数；再在训练内部比较τ={.5,1,2}、数量倍数={1,2,4}、旧配比/均衡/训练比例，三固定生成种子；最后将两个最好识别配置与两个最好生成配置交叉复核。此有限程序不称全局最优。

选择依据：内层平均宏F1；数值完全并列时按较少合成量、较小C、较短窗口、候选固定顺序。不得依据外层结果再改候选。仅真实是合法最终候选；合成仍保留比较。生成不足、收敛失败显式记录，不静默补重复文本。外层记录个体预测、各类召回、准确率、宏F1、生成种子波动和选择配置；全量部署重复同一内层程序。

接纳门槛仍在训练侧按80/85/90%一致率目标分别选择，报告覆盖与错误；85%保留共同参照，不能根据外层结果反选目标。明确规则和确认条件单列。模型更换必须使新门槛与新模型对应。

P2：先比较状态信号编码，再联合比较α={.2,.4,.5,.65,.8,1}、历史阈值={.3,.5,.7}、解除次数={1,2,3}，另列关闭保护。工程轨迹区分选择与验收变体，检查不同情境权重的稳健性。未有跨情境稳定优势则不自动替换原状态参数；心理有效性仍需要长期学生数据。

P3：保留B3/B4原代码；另立支持修订候选，区分成功支持次数与明确持续未解决，检查长历史和换题。原15轮只作回归；扩展情境只作工程验收。未经人工盲评不得宣布质量提高。先完成本地验证，真实API记录另存。

发布：以已通过验收模块构成版本，未证实候选以显式入口保留；旧版可复现。仓库仅共用代码、协议和汇总证据，真实逐条数据、模型二进制、密钥与原始调用日志放私有包。发布前源文件、模型卡、配置、数据包和运行入口共同核验。

执行中数据可行性修订（第二个外层切分R3开始前触发）：同一学生分组的部分后续训练侧类别仅1人。此时禁止基于不充分内部数据选择后续超参数，固定原C=2、1–3gram、balanced；两折预测仅作诊断，记录缺失类别，不用于声称选参成功。其外层评价仍保留。此修订因类别计数触发，不因外层分数触发；初始协议与源码哈希归档。
