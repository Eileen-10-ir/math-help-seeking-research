# 中小学生数学AI求助研究

本仓库用于小组私有代码协作。工程主线已经完成：真实数据校准的受控文本生成→识别训练→单轮判别→动态状态→画像→连续交互→云/受限云/本地支持。当前正在补齐独立语义审核和正式质量—资源对照。

## 先分清方法名

G0是旧模板增强；G1是利用真实A/L/S/P四维均值抽样行为配置的候选方法。当前联合v2是参数条件控制＋版本化数学题/语言部件的实现，不是将旧G0/G1两份语料简单相加。整体依赖标签保留原最终结论，ALSP主要用于生成，线上并不自动逐项打分。S只作信息表达控制，不直接处罚学生口语表达。

真实数据有47名学生的两次表达。训练学生校准生成器，也参与混合识别训练；留出学生用于内部识别评价。研究者已反复开发，不能称完全独立的外部验证。真实数据、数据库、模型、标注、逐条日志均不进入Git历史，通过小组私有共享包另行提供。

## 如何运行

1. clone本仓库；创建Python3.13独立环境，安装`requirements.txt`。
2. 获取三部分交接中的**内层**`共享可复现数据.zip`（约12.3MB），放仓库外。
3. 在仓库根目录执行：

```powershell
python -s -X utf8 restore_private_materials.py --archive "你保存共享可复现数据.zip的位置"
python -s -X utf8 verify_shared_release.py
python -s -X utf8 数学共同主线定版20261018/code/run_mainline.py check
python -s -X utf8 数学共同主线定版20261018/code/run_mainline.py serve --port 8771
```

恢复工具先核验整包及745项文件hash，再写缺失文件；不覆盖已修改源码。私有文件恢复后仍被默认拒绝式.gitignore忽略。仅clone没有模型和数据，不能直接启动研究主线。新输出使用`交付结果/`新目录，禁止覆盖原数据/历史结果。必要时可在独立工作副本还原共享ZIP后验收，保留已修改代码。

网页默认`http://127.0.0.1:8771/`，由本机演示；仓库发布不等于网页部署。`check`使用假API、付费0；`compare`默认离线。正式实测需要冻结病例和预算，再使用真实调用选项，保存实际返回模型而非只记商品名。密钥只用本机`MATH_DEEPSEEK_API_KEY`环境变量。API如需购买，自行购买并保留发票发给wxj统一归档。

## 当前结果与工作边界

共同参照首轮真实＋联合文本LR：内部宏F1约0.678，准确率79.6%；后续四类F1约0.599，准确率63.0%。状态v5采用阶段接纳门槛0.45/0.50、EWMA近期权重0.65及证据感知历史保护解除。单轮等级、历史后的最终档位和实际回复路径分别记录；未知/ACK不冒充已测等级。

10月18日新增的固定tau1数量比较：真实＋0/45/91条宏F1分别0.734/0.702/0.679，不能宣称合成增强已经胜出或91最优。合成数量和语义对应仍需审核。新增结果未静默覆盖冻结模型，正式比较前统一公共识别器版本。

正式比较使用同一批病例/题目/实际给定历史/初始状态/共同识别分析，比较单云、单边、协同，另加统一受限云；保存实际回复、token、时延、费用和失败。两人独立评价正确性、针对性、可执行性、连贯性、代答及阻断。允许有依据的改进和消融，不能预设协同胜出。
