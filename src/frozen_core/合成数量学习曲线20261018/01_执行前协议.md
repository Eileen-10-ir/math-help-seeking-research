# 合成数量学习曲线：预先固定的条件比较

目标：在现有生成器、文本LR、真实训练/留出划分下比较合成数量，不能证明任意分布、生成器或学生人群的全局最优。

保留当前共同主线不变。本实验独立写新目录，真实标签不改，不调用API。

候选合成预算0/45/91/182/364，均与真实训练文本混合；固定类别比例近似36:36:19，用最大余数法分配整数并保留91的36/36/19。0是仅真实强对照。固定tau1.0、同一表达器、字符TF-IDF＋LR(C2/平衡权重)、共同数学遮罩。

每个训练视图先用其训练学生校准并生成最大364条唯一文本，再按类取固定前缀得到较小预算，保证较小语料是较大语料的子集。不同数量不同时改题型/规则/生成带宽。若364无法保证唯一或契约有效，显式停止记录容量限制，不默默截断或重复凑数。

外层沿用47学生五次重复四折；同一学生和合成后代隔离。每个外层训练内部再3折，重新只用内层训练供体校准生成。内层按逐折宏F1均值选最优，再用“最优均值减其标准误”的一标准误差规则选最小合成预算；这是保守选型启发式，不是显著性证明。外层只评价选型流程与固定各预算，不用外层挑数量后称独立确认。

输出各数量的每次47人宏F1、accuracy、高/中/低召回、低→高/高→低、各折内选择、嵌套选型的外层结果、种子/供体/唯一性/参数审计与原始预测。直接报告候选范围是否有稳定收益或平台；不承诺非零合成一定更好，不按结果改网格。

本次tau固定1与旧91条外层继承tau不同，因此新91预算和旧0.678不是完全相同设置；若有差异不能全归因于数量。运行版本是否修改另作讨论，不随学习曲线自动覆盖已交接主线。

## 容量检查后的结构性修订（分类器尚未拟合、尚未查看分数）

原364条方案因遮罩后唯一表达池耗尽中断；初版脚本、协议和日志保存在history/364容量中断。随后逐级检查364、182、91、45条在20个外层及60个内层训练视图的可行性。364在首个外层视图失败，182在首个内层视图失败，91通过全部80视图。详细供体、种子和首个反例见capacity_check.json。

因此共同可行网格改为0/45/91，每视图最大唯一银行91条，小预算仍按类固定前缀嵌套。修改依据是生成容量，不是识别得分。91仅是本次已检验网格里可统一实现的最大值，不是表达库数学上限，也不能据此断言92条必然不可能。容量不足不是允许重复凑数的理由；扩展语言库另立版本后才能检验更大预算。
